Claude Code 术语速查表

本表收录 Claude Code 进阶功能的核心术语。每节课后可以回来查阅。

核心概念

.claude 目录

项目根目录下的配置文件夹，是 Claude Code 所有自定义功能的存放位置。包含 CLAUDE.md、settings.json、skills/、agents/、workflows/ 等子目录。

参见：官方文档

settings.json

Claude Code 的配置文件，可放在 ~/.claude/（全局）或 .claude/（项目级）。用于配置 permissions、hooks、环境变量、模型默认值等。

别名：settings.local.json（项目个人覆盖，被 gitignore）

CLAUDE.md

项目级指令文件。每次会话启动时加载，告诉 Claude 项目上下文、约定、规则。建议不超过 200 行。

别名：CLAUDE.md 可放在项目根目录或 .claude/ 下

扩展系统

Hook

生命周期事件触发器。在 PreToolUse、PostToolUse、SessionStart 等事件发生时自动执行 command / http / prompt / agent / mcp_tool 动作。是强制性的（每次匹配都执行）。

避免使用：钩子、触发器

参见：Lesson 1: Hooks 入门

Matcher

Hook 的匹配规则，决定 hook 在哪个工具/事件上触发。支持精确匹配（"Edit|Write"）、通配（"*"）、正则（包含特殊字符时）。

Skill

可复用的指令包，以 SKILL.md 文件形式存储在 skills/<name>/ 目录下。可通过 /skill-name 手动调用，或由 Claude 自动发现并调用（根据 description 匹配）。支持 frontmatter 元数据、参数、上下文隔离运行。

别名：slash command、指令包

Command (单文件 skill)

与 skill 类似但是单文件格式（commands/*.md），没有多文件结构。现代推荐使用 skill 格式。

Subagent / Agent（自定义）

在 agents/*.md 中定义的、拥有独立上下文窗口的专用工作器。支持自定义工具集、模型覆盖、权限模式、持久记忆（memory）、工作树隔离（worktree）。

避免使用：子Agent、小助手

Workflow

JavaScript 编排脚本（workflows/*.js），用于协调多个 subagent 按流程执行复杂任务。支持 agent()、parallel()、pipeline() 等 API。由 Claude 在 /workflows 会话中生成。

MCP (Model Context Protocol)

连接外部服务的协议（数据库、Slack、浏览器 API 等）。通过 MCP servers 可以让 Claude 在会话中直接调用外部工具。

Plugin

将 skills、hooks、subagents、MCP 打包成可安装单元。跨仓库复用或通过市场分发。

运行模式

Worktree（工作树）

Git 工作树隔离模式。subagent 在独立的临时分支上工作，互不干扰。适用于并行修改文件的场景。

Fork context（分支上下文）

Skill 的 context: fork 模式，让 skill 在独立的 subagent 上下文中运行，不污染主会话。

Skill Stacking

多个 skills 同时激活的技能栈模式（v2.1.199+）。允许组合多个技能协作完成复杂任务。

Workflow

agent()

Workflow 脚本中启动 subagent 的函数。支持 label、phase、schema（结构化输出）、model、effort、agentType 等选项。

参见：Lesson 4: Workflow 编排

parallel()

Workflow 中的并行执行函数。有全局屏障（barrier）——启动所有任务，等全部完成才继续。失败的任务返回 null。

避免使用：同时执行、并发

pipeline()

Workflow 中的流水线执行函数。无屏障——每个 item 独立经过所有阶段。总耗时 = 最慢单个 item 耗时。

避免使用：阶段执行、串行

phase()

Workflow 的阶段标记函数。将后续 agent() 调用归组到同一阶段，在进度树中显示。

Barrier（屏障）

等待所有并行任务完成后再继续执行的同步点。parallel() 自带屏障，pipeline() 没有。

Token Budget（Token 预算）

用户通过 "+500k" 等指令设定的 token 消耗上限。Workflow 脚本中通过 budget.total、budget.spent()、budget.remaining() 访问。

Meta 块

Workflow 脚本开头的 export const meta = { name, description, phases } 声明。必须是纯字面量。

Workflow Resume

中断后的 workflow 可恢复执行。已完成步骤返回缓存结果，只重跑新步骤。依赖 Date.now() 和 Math.random() 不可用。

退出码 (Hook)

Exit Code 0

Hook 执行成功 → 放行。

Exit Code 1

Hook 执行有警告 → 非阻塞错误，Claude 看到报错但继续执行。

Exit Code 2

Hook 阻止操作 → 阻断执行，stderr 反馈给 Claude。
