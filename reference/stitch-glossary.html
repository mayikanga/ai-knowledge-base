Stitch 术语速查表

Google Labs Stitch 的核心术语，随课程更新。

基础概念

Stitch

Google Labs 推出的免费 AI UI 设计工具。用自然语言描述界面，生成高保真设计稿并可导出为 Figma / HTML / React 代码。

Standard 模式

基于 Gemini 3 Flash 的快速生成模式。支持 Figma 导出，每月 ~350 次。适合日常迭代。

Experimental 模式

基于 Gemini 3 Pro 的高质量模式。支持图片/手绘输入，无 Figma 导出，每月 ~50 次。适合最终稿。

Vibe Design

意图驱动的设计理念。描述"感觉和目标"而非组件列表，让 AI 诠释和发挥。如"一个感觉像周日早晨的冥想 app"。

Infinite Canvas（无限画布）

Stitch 的无限画布空间，支持多屏共存、设计分支、交互原型连接。2026 年 3 月加入。

技术概念

DESIGN.md

开放标准的设计 Token 文件格式（Markdown）。定义颜色、字体、间距、组件规则。跨工具可导入/导出共享。

Stitch SDK

TypeScript 库（@google/stitch-sdk），提供编程式 UI 生成。核心类：Stitch、Project、Screen、DesignSystem。

参见：GitHub

Stitch MCP

Model Context Protocol 服务器，将 Stitch 的设计能力暴露给 AI 编码工具（Claude Code、Cursor、Gemini CLI 等）。

stitch-skills

Google Labs 开源的 Agent 技能库，15+ 个技能分 3 个插件组（design/build/utilities）。在 Claude Code 中可直接安装使用。

参见：GitHub

Anti-pattern（反模式）

Stitch 提示词中应避免的设计元素，如紫色渐变、对称列布局、emoji 图标、抽象 3D 球体。明确告知 AI 可避免生成"AI 感"过重的设计。
