    Transformers 原理

    Tokenizer、AutoClass、模型架构

    L1-L2 你都在用封装好的 pipeline。这课打开黑箱——pipeline 里面到底发生了什么。 理解 Tokenizer 怎么把文字变成数字、AutoClass 怎么自动匹配模型架构、模型的 forward pass 是什么样的。

    词 → 数字 → 模型 → 结果

    "I love transformers"
   ↓
① Tokenizer（分词器）
   把句子切成单词/子词 → ["I", "love", "trans", "##formers"]
   每个词映射到数字 ID → [1045, 2293, 5817, 14450]
   加上 attention_mask → [1, 1, 1, 1]
   ↓
② Model（模型）
   输入数字 ID → Transformer 网络 → 输出张量
   ↓
③ Post-processing（后处理）
   把模型输出的张量转成人类可读的结果
   → [{'label': 'POSITIVE', 'score': 0.999}]

    Tokenizer：文字 → 数字

    Tokenizer 是模型的第一道关卡——把人类语言转成模型能理解的数字 ID：

    from transformers import AutoTokenizer

# 加载分词器（和模型配套的分词器）
分词器 = AutoTokenizer.from_pretrained("bert-base-uncased")

# 编码：文字 → 数字
编码 = 分词器("Hello, how are you?", padding=True, truncation=True, return_tensors="pt")
print(编码)
# {'input_ids': tensor([[101, 7592, 1010, 2129, 2024, 2017, 1029, 102]]),
#  'attention_mask': tensor([[1, 1, 1, 1, 1, 1, 1, 1]])}

# 解码：数字 → 文字
print(分词器.decode(编码['input_ids'][0]))
# "[CLS] hello, how are you? [SEP]"
    🔍 关键概念

    input_ids — 每个词/子词对应的数字 ID（模型只能理解数字）

    attention_mask — 1 表示是有效内容，0 表示填充（padding）

    [CLS] 和 [SEP] — BERT 特殊标记，分别表示句子开头和分隔

    return_tensors="pt" — 返回 PyTorch 张量（pt = PyTorch）

    子词分词（Subword Tokenization）

    现代模型不使用"按空格切词"（那样词表太大了），而是用子词算法：

    "unbelievable"
  → ["un", "##believe", "##able"]

# BPE（Byte-Pair Encoding）——GPT 使用
# WordPiece —— BERT 使用
# Unigram —— XLNet 使用
# SentencePiece —— Llama、T5 使用

    好处："transformers" 和 "transformer" 共享 "transform" 子词，模型能学到词根意思。

    AutoClass：自动匹配模型架构

    不同的模型（BERT、GPT、T5）结构完全不同，但 transformers 用 AutoClass 统一了入口：

    from transformers import AutoTokenizer, AutoModelForSequenceClassification

# 你只需要告诉它模型名字
模型名 = "bert-base-uncased"

# 它会自动：
# 1. 从 Hugging Face Hub 下载配置
# 2. 根据配置自动选择正确的模型类（BertForSequenceClassification）
# 3. 加载预训练权重
模型 = AutoModelForSequenceClassification.from_pretrained(模型名)
分词器 = AutoTokenizer.from_pretrained(模型名)
    AutoClass匹配的模型架构用途
    AutoModel所有基础模型获取特征向量
    AutoModelForSequenceClassificationBertForSequenceClassification 等文本分类
    AutoModelForCausalLMGPT2LMHeadModel、LlamaForCausalLM 等文本生成
    AutoModelForSeq2SeqLMT5ForConditionalGeneration 等翻译/摘要
    AutoModelForQuestionAnsweringBertForQuestionAnswering 等问答

    Pipeline 拆解：手动做一遍

    以下代码演示了 pipeline("sentiment-analysis") 内部做了什么：

    from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

# 1. 加载模型和分词器
模型名 = "distilbert-base-uncased-finetuned-sst-2-english"
分词器 = AutoTokenizer.from_pretrained(模型名)
模型 = AutoModelForSequenceClassification.from_pretrained(模型名)

# 2. 分词
输入 = "This movie is fantastic!"
编码 = 分词器(输入, return_tensors="pt")
# 编码 = {'input_ids': tensor([[...]]), 'attention_mask': tensor([[...]])}

# 3. 模型推理（forward pass）
with torch.no_grad():  # 不计算梯度（推理模式）
    输出 = 模型(**编码)  # 把 input_ids 和 attention_mask 传给模型
    # 输出.logits = tensor([[-1.56,  2.84]])  # 原始分数

# 4. 后处理
概率 = torch.softmax(输出.logits, dim=1)  # 转成概率
print(概率)  # tensor([[0.012, 0.988]])  → 1.2% 负面, 98.8% 正面

标签 = ["NEGATIVE", "POSITIVE"]
预测标签 = 标签[概率.argmax().item()]
置信度 = 概率.max().item()
print(f"{预测标签}: {置信度:.4f}")
# POSITIVE: 0.988
    🔍 这段代码做了什么？

    分词器(输入, return_tensors="pt") — 把文字转成数字 ID 和 attention mask

    模型(**编码) — 把编码传给模型，执行 forward pass，返回 logits

    torch.softmax(输出.logits) — 把原始分数转成概率（和为 1）

    概率.argmax() — 取概率最高的那个标签

    三大模型架构

    架构代表模型特点典型任务
    Encoder-onlyBERT、RoBERTa双向注意力，理解整个句子分类、NER、问答
    Decoder-onlyGPT、Llama、Mistral单向注意力，逐个词生成文本生成、对话
    Encoder-DecoderT5、BART先编码理解，再解码生成翻译、摘要
