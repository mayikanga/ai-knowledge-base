    指挥大模型的命令

    给模型什么提示词，得到什么结果

    前 3 课你学会了用 transformers 加载模型、跑各种任务、理解内部原理。这课聚焦一个核心问题：怎么给模型下指令，才能拿到想要的结果。 不同的提示词、不同的参数控制、不同的输出解析方式——这就是"指挥大模型"的本质。

    一、提示词就是命令

    在 transformers 里，"给模型的命令"就是一段文本——提示词（prompt）。模型读完提示词后，根据任务类型返回不同的结果：

    任务你给模型的命令（输入）模型给你的结果（输出）
    情感分析"This movie is fantastic!"[{'label': 'POSITIVE', 'score': 0.999}]
    文本生成"Once upon a time""Once upon a time, there was a brave knight..."
    翻译"Hello, how are you?""你好，你怎么样？"
    问答问题 + 上下文从上下文中提取的答案片段
    摘要长篇文章短句概括
    零样本分类文本 + 候选标签列表每个标签的得分
    💡 核心思路

    每一类 pipeline 都对应一种"命令格式"。你给模型不同的输入结构，它就按不同的方式理解任务。

    管好"输入"和"输出"，就是管好了模型。

    二、控制文本生成——最灵活的"命令"

    文本生成 pipeline 的参数最多，也是最需要精细指挥的。来看每个参数怎么影响模型的行为：

    基础：给个开头，让它续写

    from transformers import pipeline

生成器 = pipeline("text-generation", model="gpt2")

# 最简单的命令：给一句话的开头
结果 = 生成器("人工智能的未来是")
print(结果[0]['generated_text'])
# "人工智能的未来是不可预测的，但我们可以确定的是..."

    多返回几个候选

    结果 = 生成器(
    "用 Python 写一个二分查找函数",
    max_length=100,              # 生成的文本总长度（含提示词）
    num_return_sequences=3,      # 返回 3 个不同版本
    do_sample=True,              # 采样（否则每次都一样）
)
for i, 候选 in enumerate(结果):
    print(f"\n--- 版本 {i+1} ---")
    print(候选['generated_text'])

    控制"创造力"

    # temperature：控制输出的随机性
# 低 → 保守、可预测   高 → 有创意、可能跑偏

保守 = 生成器("这个故事是关于", max_length=30, temperature=0.2, do_sample=True)
创意 = 生成器("这个故事是关于", max_length=30, temperature=0.9, do_sample=True)

print(f"保守 (0.2) : {保守[0]['generated_text']}")  # 最可能的结果
print(f"创意 (0.9) : {创意[0]['generated_text']}")  # 意想不到的续写

    Top-k 和 Top-p 采样

    # top_k：只从概率最高的 k 个词中选
# top_p（nucleus sampling）：只从累积概率超过 p 的词中选

结果 = 生成器(
    "这个故事是关于",
    max_length=50,
    do_sample=True,
    top_k=50,         # 只从 top 50 个词中选
    top_p=0.95,       # 或者从累积概率 95% 的词中选
    temperature=0.7,
)
print(结果[0]['generated_text'])
    参数作用低值 → 高值
    temperature控制随机性保守 → 有创意
    top_k只从前 K 个词中选严格 → 宽松
    top_p从累积概率 P 的词中选聚焦 → 多样
    max_length生成的最大 token 数短 → 长
    num_return_sequences返回几个候选1 → 多个
    repetition_penalty避免重复（>1.0）1.0 = 不限制

    三、常见提示词模式

    不同的任务需要不同的"命令结构"：

    指令式（Instruction）

    # 直接告诉模型要做什么
提示词 = """
请将以下英文翻译成中文：
English: "The quick brown fox jumps over the lazy dog"
中文：
"""

结果 = 生成器(提示词, max_length=100)
print(结果[0]['generated_text'])

    少样本式（Few-shot）

    # 给几个例子，让模型学模式
提示词 = """
将句子分类为"正面"或"负面"：

句子: "这个产品太棒了！"
分类: 正面

句子: "质量很差，不值这个价"
分类: 负面

句子: "用了两天就坏了"
分类:"""

结果 = 生成器(提示词, max_length=50, temperature=0.1)
print(结果[0]['generated_text'])

    结构化输出

    # 让模型按指定格式输出，方便程序解析
提示词 = """
从以下文章中提取信息，按 JSON 格式输出：

文章：特斯拉在 2023 年交付了 181 万辆汽车，总收入达 967 亿美元，
其中汽车业务收入 824 亿美元。公司目前市值约 6000 亿美元。

输出格式：
{"公司名": "", "交付量": "", "总收入": "", "市值": ""}
"""

结果 = 生成器(提示词, max_length=200, temperature=0.1)
print(结果[0]['generated_text'])

    四、非生成式 pipeline 的"命令"方式

    不只是文本生成需要下命令，其他 pipeline 也有各自的"指挥方式"：

    填空（Fill-Mask）

    from transformers import pipeline

填空 = pipeline("fill-mask", model="bert-base-uncased")

# 用 [MASK] 占位符告诉模型要填什么
结果 = 填空("I want to learn [MASK] programming language")
for 候选 in 结果:
    print(f"  {候选['token_str']}: {候选['score']:.3f}")
#  Python: 0.421
#  Java: 0.153
#  C++: 0.092
#  ...

    零样本分类（告诉模型按什么规则分类）

    零样本 = pipeline("zero-shot-classification", model="facebook/bart-large-mnli")

# "命令"由两部分组成：文本 + 候选标签
结果 = 零样本(
    "华为发布了新款折叠屏手机，售价 19999 元",
    candidate_labels=["科技", "体育", "政治", "财经"]
)
print(f"分类: {结果['labels'][0]} ({结果['scores'][0]:.2f})")
# 分类: 科技 (0.98)

    问答（告诉模型在哪找答案）

    问答 = pipeline("question-answering", model="distilbert-base-cased-distilled-squad")

# "命令" = 问题 + 上下文（告诉模型答案的范围）
结果 = 问答(
    question="Python 的作者是谁？",
    context="Python 是一种广泛使用的编程语言，由 Guido van Rossum 于 1991 年创建。"
)
print(f"答案: {结果['answer']} (置信度: {结果['score']:.2f})")

    五、解析模型输出

    理解模型返回的结构，才能在代码中正确使用：

    pipeline 类型返回结构怎么取结果
    sentiment-analysis[{'label': str, 'score': float}]结果[0]['label']
    text-generation[{'generated_text': str}]结果[0]['generated_text']
    summarization[{'summary_text': str}]结果[0]['summary_text']
    translation[{'translation_text': str}]结果[0]['translation_text']
    fill-mask[{'token_str': str, 'score': float}]结果[0]['token_str']
    question-answering{'answer': str, 'score': float}结果['answer']
    zero-shot-classification{'labels': [], 'scores': []}结果['labels'][0]
    ner[{'entity_group': str, 'word': str}]结果[0]['word']
