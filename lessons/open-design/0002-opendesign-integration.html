    集成与指挥

    MCP、Skills、设计系统、和 Claude Code 深度配合

    L1 知道了 Open Design 是什么。这课深入怎么用它指挥 Claude Code 做设计——MCP 集成、 用内置 Skills 下命令、切换品牌设计系统、让 Agent 直接写文件到你的项目里。

    MCP 集成：在 Claude Code 中操作设计项目

    安装 MCP 后，Claude Code 可以直接读写你的 Open Design 项目文件：

    # 安装 MCP（L1 已装过）
od mcp install claude

# 在 Claude Code 中可以用这些命令：
od project list                  # 列出所有设计项目
od project list --json           # JSON 格式输出
od files list <project-id>       # 查看项目文件
od files read <project-id> <path> # 读取具体文件
od plugin list                   # 列出已安装插件
od skills list                   # 列出可用 Skills
od design-system list            # 列出设计系统
    💡 MCP 的意义

    没有 MCP 时：你在 Claude Code 里聊天，设计在另一个工具里，两边不互通。

    有 MCP 后：Claude Code 可以直接读设计项目文件、切换设计系统、生成产物写进你的项目目录。

    Agent 看到的始终是实时的项目文件，不是过期的导出。

    用 Skills 下命令

    Open Design 内置 100+ Skills，每个都是你可以给 Agent 下的"设计命令"：

    # 在 Claude Code 中使用 Open Design 的 Skill
# 假设 Skill 已安装到你的 .claude/skills/ 目录

# 创建一个设计系统
/create-design-system
# → 分析你的代码库，提取颜色、字体、间距，生成 DESIGN.md

# 生成落地页
/frontend-design
# → 根据需求生成完整的前端设计稿

# 生成线框图
/wireframe
# → 快速出线框图确认布局

# 生成交互原型
/interactive-prototype
# → 可点击的交互原型

# 生成展示文稿
/make-a-deck
# → 生成 PPT 风格的展示页面（15 种模板 × 36 种主题）

    插件系统

    277 个官方插件 + 183 个参考示例，覆盖各种场景：

    # 搜索插件
od plugin search "landing page"

# 安装插件
od plugin install od-figma-migration   # 迁移 Figma 设计稿
od plugin install od-refresh-codebase  # 刷新现有代码库的品牌风格

# 查看插件信息
od plugin info od-default

# 应用插件
od plugin apply od-default --input brief="我们需要一个 SaaS 落地页"

# 创建自己的插件
od plugin scaffold --id my-plugin

    完整协作流程

    你："/create-design-system"
Agent：分析代码库 → 提取 DESIGN.md → 保存到项目

你："帮我用 Linear 的风格设计一个 Dashboard"
Agent：读取 Linear 设计系统 → 生成设计稿 → 写进项目文件

你："切换成 Stripe 的风格重新生成"
Agent：切换设计系统 → 重新生成 → 覆盖文件

你："生成一个展示文稿，发给客户看"
Agent：选 deck 模板 → 绑定当前设计系统 → 导出 HTML/PDF

你："这个按钮样式调一下"
Agent：读项目文件 → 调 CSS → 更新
