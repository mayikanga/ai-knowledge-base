    高级扫描

    多目标、认证测试、CI/CD 集成

    L1 你学会了基本扫描。这课深入高级场景——带认证的灰盒测试、多目标并行扫描、PR 自动安全检测、差异扫描减少噪音。

    认证测试（灰盒）

    需要登录的应用，用 --instruction 传入凭据：

    strix --target https://your-app.com \
  --instruction "使用账号 admin:password123 进行认证测试"

    Strix 会用这些凭据登录，然后以已认证用户身份测试越权、IDOR、权限提升等。

    多目标并行扫描

    同时扫描源码和已部署的应用：

    strix -t https://github.com/org/app -t https://your-app.com

    也可以从文件读取目标列表：

    strix --target-list ./targets.txt

    差异扫描（PR 友好）

    只扫描变更的部分，适合 Pull Request：

    strix -n --target ./ --scan-mode quick --scope-mode diff --diff-base origin/main

    只分析变更的代码行，大幅减少扫描时间和 API 消耗。

    自定义指令

    聚焦特定漏洞类型：

    # 只关注业务逻辑漏洞和 IDOR
strix --target api.your-app.com \
  --instruction "聚焦业务逻辑漏洞和 IDOR"

# 从文件读取指令
strix --target api.your-app.com \
  --instruction-file ./pentest-instructions.md

    静默模式（CI 用）

    strix -n --target https://your-app.com

    -n / --non-interactive：无交互 UI，实时打印发现，有漏洞时退出码非 0，适合自动化流程。

    GitHub Actions 集成

    # .github/workflows/strix-scan.yml
name: strix-penetration-test
on: pull_request
jobs:
  security-scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 0
      - name: Install Strix
        run: curl -sSL https://strix.ai/install | bash
      - name: Run Strix
        env:
          STRIX_LLM: ${{ secrets.STRIX_LLM }}
          LLM_API_KEY: ${{ secrets.LLM_API_KEY }}
        run: strix -n -t ./ --scan-mode quick
    💡 工作流

    开发者提 PR → GitHub Actions 触发 Strix → 自动扫描变更代码 → 发现漏洞 → PR 上标注 → 阻塞合并直到修复。

    SARIF 集成

    v1.0.0 起支持 SARIF 2.1.0 格式，可以集成到 GitHub Code Scanning 和 VS Code：

    strix -n -t ./ --sarif-output results.sarif

    之后上传到 GitHub：

    gh api /repos/org/repo/code-scanning/sarifs \
  -f sarif=@results.sarif \
  -f commit_sha=${{ github.sha }}

    动手练习

    🎯 配置 PR 自动安全扫描

    1. 创建 GitHub Actions 配置

      按上面的模板在你的项目中创建 .github/workflows/strix-scan.yml。

    2. 提交一个 PR

      故意在代码中添加一个简单的漏洞（如未授权接口），提 PR 观察 Strix 是否检测到。

    3. 查看报告

      观察 Strix 生成的 PoC 和修复建议。

    关键要点

    • --instruction 传入认证凭据做灰盒测试
    • -t 可同时指定多个目标（源码 + 线上）
    • 差异扫描 --scope-mode diff 只扫变更行，适合 PR
    • GitHub Actions 集成实现 PR 自动安全检测
    • SARIF 输出可接入 GitHub Code Scanning
