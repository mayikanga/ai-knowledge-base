    安装与配置

    工程级 AI 技能包

    你已经在 Claude Code L2 学过了 skill 是什么。Matt Pocock 的 skills 是这套机制的最佳实践——193k Stars， 由 TypeScript 专家 Matt Pocock 维护，每个技能都解决一个真实工程痛点。 这课把它装进你的 Claude Code。

    是什么？解决什么问题？

    Matt Pocock Skills 是一套面向真实工程开发的 Claude Code 技能集合。 它不是教你"vibe coding"，而是把软件工程的最佳实践（TDD、代码审查、领域建模）打包成可复用的 AI 工作流。

    痛点Agent 默认行为Matt Pocock Skills 的做法
    需求不对齐猜你要什么先面试你（/grill-with-docs）
    代码质量差一口气写一大段红-绿-重构循环（/tdd）
    架构腐烂只顾叠加功能定期架构审视（/improve-codebase-architecture）
    上下文丢失下个会话从头来交接文档（/handoff）

    安装（两种方式）

    方式一：Claude Code 插件（推荐）

    一键安装，只读不可编辑，自动更新：

    claude plugins install mattpocock-skills

    或在 Claude Code 会话内：

    /plugin install mattpocock-skills

    方式二：可编辑版

    文件存到本地项目，你可以自己改：

    npx skills@latest add mattpocock/skills

    安装时会让你选要装哪些技能、适配哪个编码工具。

    💡 选哪个？

    插件版：即装即用，自动更新，适合先体验

    可编辑版：文件在本地，你可以修改定制，适合想深度适配自己工作流的

    首次配置

    装完后，在项目目录中运行：

    /setup-matt-pocock-skills

    它会询问：

    • Issue Tracker — GitHub / Linear / 本地文件
    • Triage 标签 — 你用哪些标签（bug / feature / tech-debt 等）
    • 文档路径 — 文档存在哪里

    只需配置一次，后续所有技能都知道你的项目管理习惯。

    核心理念

    💡 和 GSD / BMAD 等框架的区别

    其他框架"接管你的流程"——你只能按它们的方式做事。

    Matt Pocock 的方式相反：技能是可组合、可修改、可控的。

    引用原话："Hack around with them. Make them your own. Enjoy."

    几个关键设计原则：

    • 用户调用 vs 模型调用 — 你决定什么时候触发流程，agent 可以在流程内自动调用子技能
    • 小型、可组合 — 每个技能只做一件事，组合使用
    • 模型无关 — Claude Code、Codex、Cursor 都能用
    • 根植于经典工程实践 — 《程序员的修炼之道》、DDD、XP、《软件设计哲学》

    技能总览

    类型技能一句话
    用户调用/grill-with-docs面试式需求梳理，建立领域模型
    /grill-me同上，但更轻量（非代码场景）
    /to-spec把当前对话转化为规格说明
    /to-tickets把计划拆成带依赖关系的任务
    /implement按规格/Ticket 实现，自动调 TDD + Review
    /improve-codebase-architecture生成架构改进报告
    模型调用/tdd红-绿-重构 TDD 循环
    /diagnosing-bugs系统性 Bug 诊断流程
    /code-review双轴审查（标准 + 规格）
    /domain-modeling构建和精炼领域模型
    /resolving-merge-conflicts按意图解决合并冲突
    /prototype快速可抛弃原型
    生产力/handoff压缩会话为交接文档
    /wayfinder规划跨会话的大块工作
