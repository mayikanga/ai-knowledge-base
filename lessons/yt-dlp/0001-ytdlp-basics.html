    yt-dlp 基础

    全能命令行音视频下载器

    yt-dlp 是目前最强大的命令行视频下载工具——支持 YouTube、Bilibili、Twitter/X、TikTok 等上千个网站， 可自由选择画质、提取音频、下载字幕、处理播放列表。

    什么是 yt-dlp？

    yt-dlp 是 youtube-dl 的活跃维护分支，用 Python 编写，支持从上千个网站下载视频和音频。 它是命令行工具——没有 GUI，但功能远超任何图形界面下载器。

    💡 核心能力

    一条命令就能：选画质 → 下载 → 自动合并 → 加字幕 → 提取音频 → 重命名文件

    安装

    # pip 安装（推荐）
pip install yt-dlp

# Windows 独立 exe
# 下载 yt-dlp.exe 放到 PATH 目录即可

# 检查版本
yt-dlp --version

    依赖：ffmpeg（用于合并视频+音频、提取音频等）

    # 检查 ffmpeg 是否已安装
ffmpeg -version

    如果没有 ffmpeg：winget install ffmpeg（Windows）或 brew install ffmpeg（Mac）

    基本下载

    # 下载最佳画质
yt-dlp "视频URL"

# 列出所有可用画质
yt-dlp -F "视频URL"

# 指定画质下载（例：选 1080p 视频 + 最佳音频）
yt-dlp -f "bestvideo[height<=1080]+bestaudio/best" "URL"

# 下载音频并转为 MP3
yt-dlp -x --audio-format mp3 "URL"

    格式选择详解

    命令含义
    -f best最佳单一文件（含音视频）
    -f bestvideo+bestaudio最佳视频 + 最佳音频（自动合并）
    -f "bestvideo[height<=1080]+bestaudio"1080p 封顶
    -f "bestvideo[ext=mp4]+bestaudio"MP4 格式的视频
    -f 137+140按 format code 指定（先用 -F 查看）
    -x --audio-format mp3提取为 MP3 音频
    --audio-quality 0最佳音频质量（0=最好，9=最差）

    输出命名

    # 默认命名：视频标题.mp4
# 自定义命名模板
yt-dlp -o "%(title)s - %(id)s.%(ext)s" "URL"

# 按上传者分类存储
yt-dlp -o "%(uploader)s/%(title)s.%(ext)s" "URL"

# 播放列表索引 + 标题
yt-dlp -o "%(playlist_index)02d - %(title)s.%(ext)s" "PLAYLIST_URL"
    变量说明
    %(title)s视频标题
    %(id)s视频 ID
    %(ext)s文件扩展名
    %(uploader)s上传者
    %(upload_date)s上传日期 (YYYYMMDD)
    %(playlist_index)s播放列表序号
    %(duration)s视频时长（秒）

    动手练习

    🎯 下载你的第一个视频

    1. 安装 yt-dlp
      pip install yt-dlp
    2. 查看可选画质
      yt-dlp -F "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
    3. 下载 720p MP4
      yt-dlp -f "bestvideo[height<=720][ext=mp4]+bestaudio" "视频URL"
    4. 提取音频
      yt-dlp -x --audio-format mp3 -o "%(title)s.%(ext)s" "视频URL"
