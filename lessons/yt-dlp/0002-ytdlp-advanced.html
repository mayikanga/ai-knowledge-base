    yt-dlp 进阶

    播放列表、字幕、Cookies、配置文件

    L1 你学会了基本下载。这课深入实战场景——批量下载播放列表、下载字幕、用浏览器 Cookies 绕过限制、 写配置文件固化常用参数。

    播放列表处理

    # 下载整个播放列表
yt-dlp "播放列表URL"

# 只下载前 5 个视频
yt-dlp -I 1:5 "播放列表URL"

# 下载第 3 到第 8 个
yt-dlp -I 3:8 "播放列表URL"

# 跳过前 2 个，下载后面所有
yt-dlp -I "2:-1" "播放列表URL"

# 只下载某几个特定视频
yt-dlp -I "1,3,5" "播放列表URL"

# 下载时不重新获取元数据（更快）
yt-dlp --flat-playlist "播放列表URL"

# 按序号命名文件
yt-dlp -o "%(playlist_index)02d - %(title)s.%(ext)s" "播放列表URL"

    字幕下载

    # 下载英语字幕
yt-dlp --write-subs --sub-langs en "URL"

# 下载中文字幕
yt-dlp --write-subs --sub-langs "zh-Hans,zh" "URL"

# 下载自动生成的字幕
yt-dlp --write-auto-subs --sub-langs "en,zh" "URL"

# 嵌入字幕到视频文件
yt-dlp --write-subs --sub-langs en --embed-subs "URL"

# 只下载字幕不下视频
yt-dlp --write-subs --sub-langs en --skip-download "URL"

    Cookies 认证

    YouTube 等网站经常要求登录后才能下载某些内容。用浏览器 Cookies 解决：

    # 从 Chrome 读取 cookies（推荐）
yt-dlp --cookies-from-browser chrome "URL"

# 从 Firefox 读取
yt-dlp --cookies-from-browser firefox "URL"

# 从 Edge 读取
yt-dlp --cookies-from-browser edge "URL"

# 导出 cookies.txt 后再用（可以复用）
yt-dlp --cookies-from-browser chrome --cookies cookies.txt "URL"
# 以后直接用
yt-dlp --cookies cookies.txt "URL"
    ⚠️ 403 错误？大概率是 cookies 过期了。重新用 --cookies-from-browser chrome 即可。

    配置文件

    把常用参数写进配置文件，每次自动生效：

    全局配置 — %APPDATA%/yt-dlp/config.txt（Windows）或 ~/.yt-dlp/config（Linux/Mac）：

    # 默认下载最佳画质
-f bestvideo[height<=1080]+bestaudio/best

# 输出命名
-o "%(uploader)s/%(title)s.%(ext)s"

# 写入字幕
--write-subs
--sub-langs en,zh

# 自动合并需用 ffmpeg
--merge-output-format mp4

# 忽略错误继续
-i

    场景命令
    更新 yt-dlpyt-dlp -U 或 pip install -U yt-dlp
    查看支持的网站yt-dlp --list-extractors
    只下载描述信息yt-dlp --skip-download --write-description
    下载缩略图yt-dlp --write-thumbnail
    限制下载速度yt-dlp --limit-rate 2M
    只下载某段时间yt-dlp --download-sections "*10:00-20:00"
    Bilibili 视频yt-dlp "https://www.bilibili.com/video/BV1xx411c7mD"
    Twitter/X 视频yt-dlp "https://x.com/user/status/123456"

    动手练习

    🎯 批量下载播放列表

    1. 找一个播放列表

      找一个你感兴趣的 YouTube 播放列表。

    2. 下载前 3 个视频
      yt-dlp -I 1:3 -o "%(playlist_index)02d - %(title)s.%(ext)s" "播放列表URL"
    3. 加上字幕
      yt-dlp -I 1:3 --write-subs --sub-langs "zh-Hans,en" -o "..." "播放列表URL"
    4. 创建配置文件

      把你常用的参数写进配置文件，以后直接 yt-dlp "URL" 就能用。
