    实战：Design-to-Code 流水线

    从想法到代码的完整闭环

    这是 Stitch 课程的最后一课。你把 L1-L5 的全部知识——提示词工程、DESIGN.md、SDK、MCP 集成—— 串成一条完整的 Design-to-Code 流水线，从一个想法出发，最终得到可运行的代码。

    项目概览

    你将搭建一条完整的流水线：

    想法描述
  ↓
① Stitch 网页 / SDK 生成设计（L1、L4）
② 用 DESIGN.md 控制设计风格（L3）
③ 通过提示词工程精调细节（L2）
④ Stitch MCP + Claude Code 导出代码（L5）
⑤ Claude Code 重构为生产级组件（CC 进阶）
  ↓
可运行的代码
    🎯 目标

    完成流水线后，你拿到的是可直接集成到项目中的代码，而不是需要大量返工的"脚手架"。

    关键：Stitch 负责"设计生成"，Claude Code 负责"代码精化"——各司其职。

    完整工作流

    第一阶段：设计（Stitch）

    步骤 工具 产出
    1. 准备 DESIGN.md Stitch 网页 / extract-design-md 设计系统文件
    2. 生成初始设计 Stitch 网页 / SDK generate() 高保真屏幕
    3. 迭代精调 Stitch 语音 / edit() / variants() 最终设计稿
    4. 导出 Stitch 导出 / SDK getHtml() HTML/CSS 或 React 代码

    第二阶段：代码（Claude Code）

    步骤 方法 产出
    5. 代码审查 Claude Code 审查导出的代码 问题清单
    6. 重构 Claude Code 拆分组件、加类型、补样式 生产级组件
    7. 集成 Claude Code 接入路由、状态管理、API 可运行的页面

    完整的提示词模板

    以下是一个端到端的提示词模板，你可以直接用在 Claude Code 中：

    帮我完成一个 Design-to-Code 流水线：

## 项目
一个叫 TaskFlow 的项目管理工具

## 设计需求
生成一个任务看板页面，包含：
- 顶部：项目名称 + 筛选器 + "新建任务"按钮
- 主体：三列看板（待办 / 进行中 / 已完成）
- 每个任务卡片含：标题、负责人、优先级标签、截止日期
- 拖拽交互的视觉暗示

## 设计风格
参考我项目中的 DESIGN.md（如果存在），如果没有：
- 蓝色主色调 #4361ee
- 圆角卡片 8px
- 简洁现代，大量留白
- 避免：紫色渐变、3D 插画、emoji

## 流程
1. 先用 Stitch 生成设计
2. 导出 HTML
3. 帮我审查导出的代码，找出需要改进的地方
4. 重构为 React + TypeScript 组件
5. 拆分组件结构，加上合理的 Props 类型

    质量检查清单

    导出 Stitch 生成的代码后，让 Claude Code 逐项检查：

    维度 检查项
    结构 组件是否拆分合理？有没有过于冗长的文件？
    类型 Props 是否有 TypeScript 类型？缺少的类型补上
    可访问性 是否有 alt 属性、role 标注、键盘导航？
    响应式 移动端是否可用？断点是否合理？
    性能 图片是否懒加载？列表是否有 key？
    设计一致性 是否遵循了 DESIGN.md 的 Token？颜色/字体是否硬编码？
    ⚠️ 记住：Stitch 的代码是"脚手架级"的

    Stitch 生成的 HTML/CSS 是功能性起点，不是生产级代码。它的强项是视觉设计，不是代码质量。

    Claude Code 的强项是代码精化——类型、重构、API 集成、状态管理。

    两者互补，不是替代。

    进阶方向

    流水线搭好后，还可以往这些方向扩展：

    方向 怎么做
    CI/CD 集成 用 Stitch SDK 在 CI 中批量生成设计稿，自动截图对比
    Claude Code workflow 编排 用 Claude Code 的 workflow 自动化整个流水线（参考 CC L4）
    Antigravity IDE 集成 Stitch + Antigravity 提供更深度的 MCP 集成体验
    多页网站生成 用 stitch-loop skill 从单个 prompt 生成完整多页网站
    Plugin 发布 把你的流水线打包为 Claude Code plugin 分享给团队

    动手练习

    🎯 练习：跑一次完整的 Design-to-Code 流水线

    步骤：

    1. 选一个真实需求

      选你项目中一个需要新页面的功能——登录页、仪表盘、设置页都可以。

    2. 准备 DESIGN.md

      如果你的项目已经有设计规范，用 Stitch 的"从 URL 提取"或 stitch::extract-design-md 生成 DESIGN.md。

    3. 在 Stitch 中生成设计

      使用 L2 的结构化提示词方法，生成页面设计。

    4. 导出 + Claude Code 精化

      导出 HTML，让 Claude Code 审查、重构、加类型、集成到你的项目中。

    5. 对比前后

      比较直接使用 Stitch 导出代码 vs 经过 Claude Code 精化后的代码质量差异。
