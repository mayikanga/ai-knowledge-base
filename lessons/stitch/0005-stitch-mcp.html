Stitch · Lesson 5 / 6

    Stitch MCP + Claude Code

    你的 Claude Code × Stitch

    这是整个课程中你最有优势的一课——你学完了 Claude Code 进阶 6 课，又学了 Stitch 前 4 课。 现在把两者连起来：在 Claude Code 中直接调用 Stitch 的设计能力。

    什么是 Stitch MCP？

    Stitch MCP（Model Context Protocol）是一个服务器，将 Stitch 的设计能力以工具的形式暴露给 AI 编码工具。 配置后，Claude Code 可以直接在你的项目目录中调用 Stitch 生成设计、创建设计系统、导出代码， 不再需要在网页和终端之间来回切换。

    💡 没有 MCP 时

    手动打开 Stitch 网页 → 写提示词 → 生成 → 导出 HTML → 回到 Claude Code → "帮我把这个 HTML 改成 React 组件"

    💡 有 MCP 时

    直接在对话中说："帮 TaskFlow 生成一个登录页面设计，然后转成 React 组件" → Claude Code 自动调 Stitch → 出设计 → 转代码

    配置 Stitch MCP

    在 Claude Code 中配置 Stitch MCP 服务器。编辑 .claude/settings.json：

    {
  "mcpServers": {
    "stitch": {
      "command": "npx",
      "args": ["-y", "@google/stitch-mcp-server"],
      "env": {
        "STITCH_API_KEY": "你的API密钥"
      }
    }
  }
}

    或者在 Claude Code 中直接运行：

    /mcp add stitch -- npx -y @google/stitch-mcp-server
    ⚠️ 前提：需要先申请 Stitch API 密钥（在 stitch.withgoogle.com 的设置页面获取）。

    验证连接

    配置后在 Claude Code 中运行：

    /mcp

    如果看到 stitch 出现在列表中，说明连接成功。可以测试一下：

    "用 Stitch 为当前项目生成一个登录页面的设计"

    Claude Code 会调用 Stitch MCP 工具，生成设计并返回结果。

    安装 stitch-skills

    Google Labs 提供了 stitch-skills，包含 15 个专门针对 Stitch 的技能，分 3 个插件组。 安装后在 Claude Code 中可以直接通过 /skill-name 调用。

    安装完整插件（推荐）

    npx plugins add google-labs-code/stitch-skills --scope project --target claude-code

    三个插件组

    插件 技能数 核心技能
    stitch-design 6 generate-design、manage-design-system、extract-design-md
    stitch-build 5 react-components、react-native、shadcn-ui
    stitch-utilities 4 design-md、enhance-prompt、stitch-loop、taste-design

    技能详解

    stitch-design（设计工作流）

    技能作用
    stitch::code-to-design将前端代码转换为 Stitch 设计
    stitch::generate-design从文本或图片生成新屏幕
    stitch::manage-design-system管理 DESIGN.md 并应用到屏幕
    stitch::extract-design-md从前端代码中提取 DESIGN.md
    stitch::extract-static-html从运行的 Web 应用提取静态 HTML
    stitch::upload-to-stitch将本地资源上传到 Stitch 项目

    stitch-build（代码生成）

    技能作用
    stitch::react-componentsStitch 设计 → React 组件系统
    stitch::react-nativeStitch 设计 → React Native 组件
    remotion用 Remotion 生成导览视频
    shadcn-uishadcn/ui 组件集成指导
    react-vite-dashboardStitch → React + Vite 仪表盘

    stitch-utilities（辅助工具）

    技能作用
    design-md分析项目生成 DESIGN.md
    enhance-prompt把模糊想法优化为结构化 prompt
    stitch-loop从单个 prompt 生成完整多页网站
    taste-design生成"高级、反通用"的 DESIGN.md

    典型工作流

    设计 → 代码

    你："/stitch::generate-design 为一个项目管理工具生成仪表盘页面"
Claude Code：调用 Stitch MCP → 生成设计
你："帮我把这个设计转成 React 组件"
Claude Code：调用 stitch::react-components → 输出组件代码

    代码 → 设计（反向）

    你："/stitch::extract-design-md 从我的组件库提取设计系统"
Claude Code：分析源码 → 生成 DESIGN.md
你："把这份 DESIGN.md 导入 Stitch 并生成一个新的用户设置页面"
Claude Code：调用 stitch::manage-design-system → 应用 → 生成

    全自动流水线

    你："帮我把这个项目重新设计一下——先提取当前设计系统，
     然后生成一套新的页面设计，最后转成 React 组件"
Claude Code 依次自动调用：
  1. stitch::code-to-design（读当前代码）
  2. stitch::generate-design（生成新设计）
  3. stitch::react-components（转 React 组件）

    本课关键要点

    💡 核心记忆点
    • Stitch MCP 把 Stitch 设计能力暴露为 Claude Code 可直接调用的工具
    • 通过 .claude/settings.json 的 mcpServers 配置
    • stitch-skills 提供 15 个技能，分 design / build / utilities 三组

    • 可以实现双向同步：代码↔DESIGN.md↔Stitch 设计
