    Stitch SDK

    编程式 UI 生成

    前三课你都是通过 Stitch 网页界面操作的。这一课将带你进入程序员的主场——用 TypeScript 代码调用 Stitch 的能力， 把 UI 生成集成到你的开发工作流中。

    SDK 概览

    @google/stitch-sdk 是 Google 开源的 TypeScript 库（Apache 2.0 许可），让你通过代码调用 Stitch 的全部能力： 创建项目、生成屏幕、编辑设计、导出 HTML 和截图。

    💡 和网页版的区别

    网页版 Stitch — 手动操作，适合探索和快速原型

    Stitch SDK — 编程调用，适合自动化、批量生成、集成到 CI/CD

    两者互通——网页版创建的项目 SDK 也能访问，反之亦然。

    安装和初始化

    npm install @google/stitch-sdk

    需要 API 密钥，设置为环境变量：

    export STITCH_API_KEY="your-api-key"

    在代码中使用：

    import { stitch } from "@google/stitch-sdk";

// 单例模式，自动读取 STITCH_API_KEY
const project = stitch.project("your-project-id");
const screen = await project.generate("一个登录页面");
const html = await screen.getHtml();

    核心类与方法

    类 方法 说明
    Stitch stitch.projects() 列出所有项目
    stitch.project(id) 按 ID 引用项目
    Project project.generate(prompt, deviceType?) 根据提示词生成屏幕
    project.screens() 列出项目所有屏幕
    project.getScreen(screenId) 获取特定屏幕
    project.createDesignSystem(ds) 创建设计系统
    project.listDesignSystems() 列出设计系统
    Screen screen.edit(prompt) 通过提示词编辑屏幕
    screen.variants(prompt, options) 生成设计变体
    screen.getHtml() 获取 HTML 下载 URL
    screen.getImage() 获取截图下载 URL
    DesignSystem ds.update(designSystem) 更新设计系统
    ds.apply(screens) 应用到指定屏幕

    设备类型

    generate() 和 edit() 支持指定目标设备：

    值 说明
    "MOBILE"移动端布局
    "DESKTOP"桌面端布局
    "TABLET"平板布局
    "AGNOSTIC"自适应布局

    变体生成

    variants() 可以从一个屏幕生成多个设计方向：

    const variants = await screen.variants(
  "让它更适合企业用户",
  {
    variantCount: 3,        // 生成数量 (1-5)
    creativeRange: "EXPLORE", // REFINE / EXPLORE / REIMAGINE
    aspects: ["COLOR_SCHEME", "LAYOUT"],
  }
);
    参数 可选值 说明
    variantCount 1-5 变体数量
    creativeRange REFINE / EXPLORE / REIMAGINE 微调 / 探索 / 重新想象
    aspects LAYOUT, COLOR_SCHEME, IMAGES, TEXT_FONT, TEXT_CONTENT 要变化的维度

    错误处理

    SDK 方法失败时抛出 StitchError：

    import { StitchError } from "@google/stitch-sdk";

try {
  const screen = await project.generate("...");
} catch (e) {
  if (e instanceof StitchError) {
    console.error(e.code);    // AUTH_FAILED, RATE_LIMITED, 等
    console.error(e.message); // 人类可读的描述
    console.error(e.recoverable); // 是否可重试
  }
}
    错误码 说明
    AUTH_FAILEDAPI 密钥无效
    RATE_LIMITED配额超限
    NOT_FOUND项目/屏幕不存在
    PERMISSION_DENIED无权限
    NETWORK_ERROR网络问题
    VALIDATION_ERROR参数错误
    UNKNOWN_ERROR其他错误

    AI 框架集成

    SDK 原生支持与主流 AI 框架集成：

    Vercel AI SDK

    import { stitchTools } from "@google/stitch-sdk/ai";
import { generateText } from "ai";

const tools = stitchTools({
  include: ["create_project", "generate_screen_from_text", "get_screen"]
});

const result = await generateText({
  model: yourModel,
  tools,
  prompt: "帮我创建一个登录页面项目",
});

    Google ADK

    import { stitchAdkTools } from "@google/stitch-sdk/adk";

    动手练习

    🎯 练习：用 SDK 生成一个屏幕并导出

    步骤：

    1. 安装 SDK 
      mkdir stitch-demo && cd stitch-demo
npm init -y
npm install @google/stitch-sdk
# 设置环境变量
# set STITCH_API_KEY=your-api-key
    2. 写一个脚本生成屏幕

      创建 generate.mjs：

      import { stitch } from "@google/stitch-sdk";

const project = stitch.project("你的项目ID");
const screen = await project.generate(
  "一个简洁的登录页面，蓝色主色调，邮箱密码输入框",
  "DESKTOP"
);

const html = await screen.getHtml();
const image = await screen.getImage();

console.log("HTML:", html);
console.log("截图:", image);
