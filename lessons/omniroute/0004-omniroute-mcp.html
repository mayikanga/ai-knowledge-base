OmniRoute · Lesson 4 / 6

    MCP + 编程代理集成

    中转站实战

    OmniRoute 自带了一个 MCP 服务器（94 个工具）和一个 A2A 代理协议。这一课教你如何把 Claude Code（以及你学过的其他工具）接入 OmniRoute，让它成为你所有 AI 操作的"总开关"。

    把 Claude Code 接入 OmniRoute

    这是最直接的用法——让 Claude Code 通过 OmniRoute 访问模型：

    # 启动 OmniRoute
omniroute

# 在 Claude Code 中配置
# ~/.claude/settings.json
{
  "model": "auto/coding",
  "apiEndpoint": "http://localhost:20128/v1"
}

# 或者使用自动配置命令
omniroute setup-claude-code

    Claude Code 的所有请求都会经过 OmniRoute，自动享受故障转移、压缩、成本优化。

    OmniRoute 的 MCP 服务器

    OmniRoute 自带一个功能完整的 MCP 服务器（94 个工具、30 个范围、完整审计追踪）：

    传输方式端点
    stdioomniroute --mcp
    HTTPhttp://localhost:20128/api/mcp/stream
    SSEhttp://localhost:20128/api/mcp/sse

    在 Claude Code 中连接：

    claude mcp add-server omniroute \
  --type http \
  --url http://localhost:20128/api/mcp/stream

    MCP 工具覆盖：提供商管理、组合管理、缓存操作、健康检查、配额监控等。

    一键配置所有工具

    OmniRoute 提供 setup-* 系列命令，一键配置各种编程工具：

    omniroute setup-claude-code   # 配置 Claude Code
omniroute setup-codex          # 配置 Codex CLI
omniroute setup-cursor         # 配置 Cursor
omniroute setup-copilot        # 配置 GitHub Copilot
omniroute setup-celine         # 配置 Cline / Roo Code
omniroute setup-aider          # 配置 Aider
omniroute setup-opencode       # 配置 OpenCode

    A2A 代理协议

    OmniRoute 还支持 Google 的 A2A（Agent-to-Agent）协议，让多个 AI 代理直接通信协作：

    • 端点：http://localhost:20128/.well-known/agent.json
    • 协议：JSON-RPC 2.0 + SSE
    • 6 个内置 A2A skill，用于代理间通信

    多工具共享一个网关

    一个 OmniRoute 实例可以同时服务多个工具——每个工具只需指向同一个 localhost:20128：

    Claude Code  → http://localhost:20128/v1  ← 模型: auto/coding
Cursor       → http://localhost:20128/v1  ← 模型: auto/fast
Copilot      → http://localhost:20128/v1  ← 模型: auto/cheap

    动手练习

    🎯 把 Claude Code 接入 OmniRoute

    1. 确认 OmniRoute 在运行
      omniroute
    2. 配置 Claude Code
      omniroute setup-claude-code
    3. 验证

      在 Claude Code 中问一个问题，观察 OmniRoute 仪表板中出现请求记录。

    4. 添加第二个工具

      如果有 Cursor 或 Continue，用对应的 setup 命令接入同一个 OmniRoute。

    关键要点

    • Claude Code 只需配置 apiEndpoint 即可接入 OmniRoute
    • OmniRoute 自带 MCP 服务器（94 工具），可通过 HTTP/SSE/stdio 连接
    • setup-* 系列命令一键配置所有主流编程工具
    • 一个 OmniRoute 实例可同时服务多个工具，各自指定不同模型
    • A2A 协议支持代理间直接通信协作
