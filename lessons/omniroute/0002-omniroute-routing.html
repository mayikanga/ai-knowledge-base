    路由策略

    智能调度你的模型

    L1 你启动了 OmniRoute，知道了它是一个 AI 交换机。这一课讲交换机怎么决定把请求发给谁——18 种路由策略，从最简单的"按顺序"到最智能的"多模型融合"。

    Auto-Combo：零配置智能路由

    把模型设为 auto，OmniRoute 会自动从已连接的提供商中构建一个组合，基于 12 个因素实时打分选择：

    模型 ID优化目标
    auto平衡默认（LKGP — 保持上次成功的提供商）
    auto/coding代码生成优先质量
    auto/fast最低延迟
    auto/cheap最低价格
    auto/smart质量优先 + 10% 探索

    18 种路由策略速览

    策略行为适用场景
    priority按优先级列表顺序，用尽再切有明确偏好的提供商
    fill-first填满一个目标配额再切想用尽免费额度
    weighted按权重随机分配负载按比例分布
    round-robin轮询循环均匀分配
    cost-optimized最低价格优先成本敏感场景
    headroom剩余配额最多的优先避免配额耗尽
    latency-first最低延迟优先实时交互
    lkgp粘着上次成功的提供商稳定性优先
    fusion多模型投票，裁判合成关键决策
    pipeline链式处理，一个输出给下一个多步骤工作流

    配置组合（Combo）

    你可以把多个模型串成一个"组合"，定义故障转移链：

    omniroute combo create my-stack \
  --model gpt-4o \
  --fallback claude-sonnet-4.5 \
  --fallback auto/coding

    使用组合：在工具中把模型设为 my-stack。

    Fusion 策略

    同时发给多个模型，让裁判模型合成最佳答案：

    omniroute combo create code-review \
  --strategy fusion \
  --model gpt-5:claude-opus-5:gemini-3-pro \
  --fusion-judge claude-sonnet-4.5

    三層韧性

    层范围作用
    断路器整个提供商上游失败时停止请求，自动探测恢复
    连接冷却一个账号/密钥限流的密钥跳过，其他密钥继续服务
    模型锁定提供商+模型单个模型配额耗尽隔离，不影响整体

    动手练习

    🎯 创建一个组合

    1. 查看可用提供商
      omniroute providers list
    2. 创建一个 3 层组合
      omniroute combo create daily-coding \
  --model auto/coding \
  --fallback auto/cheap \
  --fallback auto/offline
    3. 测试组合

      在对话中选择模型 daily-coding，观察 OmniRoute 如何路由。

    关键要点

    • Auto-Combo 零配置即可智能路由（12 因素实时打分）
    • Combo 可以串联多个模型作为故障转移链
    • Fusion 策略让多个模型投票，裁判合成最佳答案
    • 三层韧性机制（断路器/冷却/锁定）确保高可用
    • 用 omniroute combo 命令管理组合
