    OmniRoute 基础

    统一 AI 网关

    你学过了 Claude Code（AI 编码工具）和 Stitch（AI 设计工具）。OmniRoute 是连接它们的基础设施—— 一个统一网关，让你用一个端点对接 250+ AI 提供商，自动做故障转移、成本优化、Token 压缩。

    什么是 OmniRoute？

    OmniRoute 是一个开源的 AI 网关（MIT 许可），运行在你自己的机器上。它在你的编程工具和 AI 提供商之间插入一层， 提供统一的 /v1 端点（兼容 OpenAI 格式），自动处理路由、故障转移、配额管理、成本优化。

    💡 一句话理解

    OmniRoute = 你的 AI "交换机"。所有工具（Claude Code、Cursor、Cline…）接到一个口，由它帮你智能分配到最合适的 AI 模型。

    架构与请求流

    你的工具（Claude Code / Cursor / Cline …）
        ↓
http://localhost:20128/v1
        ↓
OmniRoute 智能路由器
        ↓
4 层故障转移：订阅 → API Key → 低价模型 → 免费模型
        ↓
250+ AI 提供商（OpenAI / Anthropic / Google / 免费提供商…）

    能力说明
    250+ 提供商所有主流 AI 厂商 + 社区网关，90+ 有免费层

    安装

    npm install -g omniroute
omniroute

    启动后：

    • 仪表板：http://localhost:20128
    • API 端点：http://localhost:20128/v1

    动手练习

    🎯 练习：安装并启动 OmniRoute

    1. 安装
      npm install -g omniroute
    2. 启动
      omniroute
    3. 打开仪表板

      浏览器打开 http://localhost:20128，看看仪表板。

    4. 查看提供商列表

      在仪表板中查看可用的提供商和模型。
      注意那些标注"免费"的提供商。

    关键要点

    • OmniRoute 是一个本地运行的 AI 网关，统一管理所有 AI 调用
    • 对接 250+ 提供商，90+ 有免费层，11 个永久免费
    • 兼容 24+ 编程工具，包括你刚学完的 Claude Code
    • 核心价值：故障转移 + 成本优化 + Token 压缩
    • 启动后所有工具指向 http://localhost:20128/v1 即可
