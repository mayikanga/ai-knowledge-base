    CLI 与运维

    80+ 命令的玩法

    OmniRoute 不只是一个网关——它还自带一个功能完整的 CLI（80+ 命令）和一个 Web 仪表板。这一课带你覆盖最常用的运维操作：提供商管理、组合管理、缓存、健康监控、远程管理等。

    核心命令

    命令作用
    omniroute启动网关 + 仪表板
    omniroute chat交互式 TUI 聊天客户端
    omniroute setup引导式首次配置向导
    omniroute doctor诊断提供商、端口、原生依赖

    远程管理

    用 scoped token 从任何机器管理远程 OmniRoute 实例：

    omniroute connect 192.168.0.15     # 密码 → scoped token
omniroute models list              # 针对远程服务器执行
omniroute tokens create --name ci --scope read   # 创建更窄的 token
omniroute contexts use default     # 切回本地

    Web 仪表板

    浏览器打开 http://localhost:20128，可视化操作所有功能：

    • 提供商状态面板 — 实时健康监控
    • 请求实时流 — 看到每个请求的路由
    • 成本分析 — 按提供商/模型/工具的费用 breakdown
    • 压缩工作室 — 拖拽排序 10 引擎管线
    • 组合设计器 — 可视化创建和测试路由组合
    • 配额仪表板 — 免费额度剩余多少一目了然
